# code-pet

> Claude Code로 작업하는 동안 **날씨 인사 · 에러/해결 팝업 · 저장 알림 · 완료 알림창(토큰 사용량 포함)**을 띄워주는 코드 펫 훅 플러그인입니다. (Windows 전용)

## 훅 이름

플러그인 이름은 `code-pet`이고, 아래 훅 5개가 들어 있습니다.

| 이벤트 | 대상 | 스크립트 | 하는 일 |
|---|---|---|---|
| `UserPromptSubmit` | 모든 프롬프트 | `pet.py prompt` | 하루 첫 프롬프트면 날씨 인사 팝업을 띄웁니다. |
| `PostToolUse` | `Write\|Edit` | `after-edit.py` | 저장됨 토스트를 띄우고, `.py`면 ruff로 포맷·린트하고 문제를 Claude에게 알려줍니다. |
| `PostToolUse` | 모든 도구 | `pet.py tool` | 상태줄 화이팅 문구를 갱신하고, 에러 났던 명령이 성공하면 해결 팝업을 띄웁니다. |
| `PostToolUseFailure` | `Bash` | `pet.py fail` | 명령이 에러로 끝나면 시무룩 팝업을 띄웁니다. |
| `Stop` | 답변 끝 | `notify.py` | 화면 가운데에 완료 알림창(요약, 펫 표정, 토큰 오늘/총)을 띄웁니다. |

## 요구사항

- Windows 10/11 (팝업은 PowerShell + WinForms로 그립니다)
- Python 3.8 이상이 `python` 명령으로 실행되어야 합니다
- (선택) `pip install ruff` : `.py` 저장 시 자동 포맷·린트

## 설치

Claude Code 안에서:

```
/plugin marketplace add sayluaa/code-pet
/plugin install code-pet@code-pet
```

터미널에서:

```
claude plugin marketplace add sayluaa/code-pet
claude plugin install code-pet@code-pet
```

설치한 뒤 Claude Code를 새로 시작하면 적용됩니다. `/plugin`에서 `code-pet`이 켜져 있는지 확인할 수 있어요.

## 사용 예시

설치만 하면 따로 명령은 없고, 평소처럼 작업하면 펫이 반응합니다.

**1. 하루 첫 작업: 날씨 인사**
오늘 첫 프롬프트를 보내면 오른쪽 위에 팝업이 9초 뜹니다.
```
(^o^)/   오늘도 같이 힘내봐요!
         좋은 아침이에요 · Seoul
         구름 조금 16° (최고 19° / 최저 14°)
         비 올 수 있어요, 우산 챙기세요 (강수 80%)
```

**2. 에러가 나면: 시무룩 → 해결하면: 기쁨**
Claude가 실행한 Bash 명령이 에러로 끝나면 시무룩 팝업이 뜨고, 상태줄도 시무룩 상태가 됩니다.
```
(ㅠ_ㅠ)  괜찮아요, 같이 고쳐봐요
         명령을 실행하다 에러가 났어요
         python demo.py
```
같은 명령이 성공하면 팝업이 기쁨으로 바뀝니다.
```
\(^▽^)/  해냈다! 대단해요!
         아까 에러가 났던 명령이 이번엔 성공했어요
```
`grep`처럼 결과가 없어도 exit 1인 명령은 에러로 치지 않고, 에러 팝업은 60초에 한 번만 뜹니다.

**3. 파일을 저장하면: 저장됨 토스트**
Claude가 파일을 쓰거나 고칠 때마다 오른쪽 위에 토스트가 3초 뜹니다. 펫 팝업이 떠 있으면 그 바로 아래에 붙어요.
```
● 저장됨  demo.py
  포맷 그대로 · 린트 통과
```

**4. 답변이 끝나면: 완료 알림창**
화면 가운데에 10초 뜹니다. 답변 마지막의 `[요약]` 줄(없으면 첫 줄)이 요약으로 들어갑니다.
```
        Claude 답변이 완료되었습니다
              (*^o^*)v
          오늘도 해냈어요!
   ┌───────────────────────────┐
   │  Stop 훅 · 알림창 · 요약 줄  │
   └───────────────────────────┘
      토큰  오늘 416.9K / 총 3.82M
              [ 확인 (10) ]
```
도구를 쓴 턴이면 뿌듯, 대화만 했으면 가벼운 인사, 에러가 남은 채 끝났으면 걱정 표정이 나옵니다.

## 알림 위치

| 알림 | 위치 |
|---|---|
| 펫 팝업(인사, 에러, 해결) | 오른쪽 위 |
| 저장됨 토스트 | 오른쪽 위 (펫 팝업이 있으면 그 아래) |
| 답변 완료 알림창 | 화면 가운데 |

## 설정

처음 실행하면 `%USERPROFILE%\.claude\code-pet\config.json`이 만들어집니다. 직접 고치면 바로 적용돼요.

| 항목 | 기본값 | 설명 |
|---|---|---|
| `cheer_every` | `5` | 도구를 이 횟수만큼 쓸 때마다 화이팅 문구를 바꿉니다. |
| `sad_popup_gap_sec` | `60` | 에러 팝업 사이의 최소 간격(초) |
| `unresolved_expire_sec` | `1800` | 이 시간이 지나도 해결 못 하면 시무룩을 풀어줍니다. |
| `count_cache_read` | `false` | `true`면 캐시에서 읽은 토큰도 사용량에 합칩니다. |
| `location_override` | `null` | 위치를 고정합니다. 예: `{"city": "서울", "lat": 37.57, "lon": 126.98}` |

데이터 폴더 위치는 환경 변수 `CODE_PET_DATA`로 바꿀 수 있습니다.

### 펫 GIF 넣기 (선택)

`%USERPROFILE%\.claude\code-pet\gifs\` 폴더에 표정별 GIF를 넣으면 팝업에서 움직이는 그림으로 나옵니다. 없으면 텍스트 이모티콘이 나와요.

| 파일 | 쓰이는 때 | 없을 때 대신 쓰는 파일 |
|---|---|---|
| `hello.gif` | 날씨 인사 | |
| `sad.gif` | 에러 | |
| `happy.gif` | 해결 | |
| `proud.gif` | 작업 마무리 | `happy.gif` |
| `worry.gif` | 에러가 남은 채 끝남 | `sad.gif` |
| `chat.gif` | 대화만 하고 끝남 | `cheer.gif` |
| `default.gif` | 위에 없는 표정 공통 | |

배경이 투명한 GIF가 어두운 팝업에 가장 잘 어울리고, 96px 정도로 줄어들어 표시됩니다. **직접 만들었거나 사용 권한이 있는 그림만 쓰세요.**

## 선택: 상태줄에 펫 문구 붙이기

플러그인은 사용자의 상태줄 설정을 바꾸지 못해서, 원하면 직접 한 번 붙여야 합니다. 상태줄 스크립트(`~/.claude/statusline-command.sh` 등)의 마지막 출력 직전에 아래를 넣으세요.

```bash
# 코드 펫: 문구가 아직 유효할 때만 붙인다 ('만료시각<TAB>문구' 형식)
pet_file="${CODE_PET_DATA:-$HOME/.claude/code-pet}/status.txt"
if [ -f "$pet_file" ]; then
  IFS=$'\t' read -r pet_exp pet_txt < "$pet_file"
  if [ -n "$pet_txt" ] && [ "$(date +%s)" -lt "${pet_exp:-0}" ]; then
    out="${out} | ${pet_txt}"   # out 은 상태줄 문자열 변수
  fi
fi
```

## 선택: 알림창 요약을 더 잘 나오게 하기

`CLAUDE.md`에 아래 규칙을 넣으면 완료 알림창에 핵심 키워드가 깔끔하게 들어갑니다. 없으면 답변 첫 줄 일부가 대신 나와요.

```
모든 최종 답변의 맨 마지막 줄에 `[요약] 키워드 · 키워드 · 키워드` 형식의 한 줄을 붙인다. (키워드 2~4개, 한국어 명사구)
```

## 개인정보와 네트워크

- **외부 요청은 하루 한 번의 날씨 조회뿐입니다.** IP로 대략적인 위치를 얻기 위해 `ipwho.is`에, 날씨를 받기 위해 `open-meteo.com`에 요청합니다. 위치를 고정(`location_override`)하면 `ipwho.is`는 호출하지 않아요.
- **토큰 집계는 내 PC에서만 합니다.** `~/.claude/projects/`의 대화 기록에서 토큰 수(`usage`)만 읽고, 대화 내용이나 집계 결과는 어디로도 보내지 않습니다.
- 상태, 위치 캐시, 토큰 장부는 모두 `%USERPROFILE%\.claude\code-pet\`에만 저장됩니다.

## 문제 해결

- **팝업이 안 떠요:** `python --version`이 되는지, 데이터 폴더의 `error.log`에 내용이 있는지 확인하세요.
- **토큰이 너무 크게/작게 나와요:** 기본은 입력 + 캐시 생성 + 출력의 합이고 캐시 읽기는 뺍니다. `count_cache_read`로 바꿀 수 있어요.
- **"총" 토큰은 언제부터인가요:** 처음 설치한 시점에 남아 있던 대화 기록부터 센 뒤, 이후에는 장부에 계속 쌓입니다.

## 제거

```
/plugin uninstall code-pet@code-pet
```

저장된 데이터까지 지우려면 `%USERPROFILE%\.claude\code-pet\` 폴더를 삭제하세요.
